Building systems that quietly carry a lot of weight.

I'm a software engineer based in Dallas, TX, with 6+ years of experience building and scaling systems at high-growth startups. Earlier in my career, I built software for Mobihealth, a healthcare startup connecting doctors and patients to improve medical adherence, Smart City dashboards powered by Python ETL pipelines, and IoT software for medical devices. If any of this sounds like a problem you're trying to solve, I'd love to talk.
